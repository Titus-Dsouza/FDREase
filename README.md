# AICTE FDR Portal

**Simplifying Security Deposit and Fixed Deposit Receipt (FDR) Management.**

## About the Project

The AICTE FDR Portal is a simple, AI-assisted platform designed to streamline the submission, verification and tracking of institutional security deposits and FDRs.

It aims to reduce manual document checking, identify discrepancies early and make the verification process more transparent for institutions and AICTE officials.

## Key Features

- **Smart Document Validation:** Extract FDR details and flag missing or inconsistent information.
- **FDR Verification:** Support verification through authorized sources.
- **Clear Status Tracking:** Track submissions, pending verification and required actions.
- **Maturity Alerts:** Highlight FDRs approaching maturity.
- **Audit Trail:** Maintain a record of verification results and official actions.
- **Simple Dashboard:** Clean, minimal and easy-to-use interface.

## User Roles

- **Institutions:** Submit FDR details, upload documents and track applications.
- **AICTE Officials:** Review submissions, inspect discrepancies and manage verification workflows.
- **Administrators:** Manage users, validation rules and system settings.

## Proposed Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Document Processing:** OCR and automated validation rules

## Our Differentiator

**One upload. Automated checks. One clear status. Every issue explained.**

The platform prioritizes simplicity, transparency and efficient document scrutiny over unnecessary complexity.

## Important Note

This project is a Smart India Hackathon (SIH) prototype. Demonstration data and simulated verification services, where used, are clearly identified. AI-generated findings support human review and do not replace official regulatory decisions.
