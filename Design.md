# Design.md — AICTE FDR Portal

## Design Goal
Create a simple, professional website that feels easy to understand and never overwhelms users.

## Theme
- **Light mode:** Soft off-white background, white cards, dark text.
- **Dark mode:** Deep charcoal background, slightly lighter cards, light text.
- **Accent colour:** Calm blue for buttons, links, and active navigation.
- Support one-click switching between light and dark modes.

## UI Rules
- Use one consistent colour palette across both dashboards.
- Keep layouts spacious, with clear headings and readable text.
- Use simple cards, tables, forms, and familiar icons.
- Show only essential information on each screen.
- Use plain labels instead of technical jargon.
- Keep primary buttons obvious and consistent.
- Use clear status labels: Pending, Under Review, Approved, and Rejected.
- Make the website responsive for mobile and desktop.
- Avoid unnecessary animations, gradients, decorative images, and pop-ups.

## Layout
- **Institution Dashboard:** Submit FDR, view applications, track status, and see reminders.
- **Official Dashboard:** Review applications, inspect warnings, request corrections, and record decisions.
- Keep navigation consistent and easy to find.

## Accessibility
- Maintain readable contrast and font sizes.
- Clearly label every form field.
- Show helpful validation messages beside errors.
- Never communicate status using colour alone.

## Design Principle
**Simple, calm, consistent, and easy to use.**
